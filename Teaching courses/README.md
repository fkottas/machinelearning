## How the course area will grow

Each week will be added as one self-contained package:

```text
Teaching courses/
└── Machine Learning in Finance/
    └── 2026-2027/
        ├── syllabus/
        ├── lectures/
        │   └── lecture-XX-topic/
        │       ├── README.md
        │       ├── slides/
        │       ├── notebooks/
        │       ├── data/
        │       └── assignment/
        ├── datasets/
        ├── assignments/
        ├── project/
        └── reference/
```

The presentation, Colab, data, explanation and assignment for a week stay together. This keeps the e-class easy to update without mixing course material with research code or the credit-risk book.
