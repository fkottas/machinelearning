## Course purpose

This course connects the mathematical foundations of machine learning with practical financial decision-making. The primary application is credit-risk analytics, including default prediction, credit scoring, probability of default, model evaluation, calibration, and explainable AI. The course also introduces applications in fraud detection, financial analytics, forecasting, and investment decision support.

## Weekly material standard

Each week will use the same navigation pattern:

1. Lecture presentation in PPTX and PDF format
2. Lecture notes and key concepts
3. Guided Google Colab notebook
4. Supporting Python script
5. Dataset instructions and data dictionary
6. Weekly exercise and expected deliverables
7. Reading list and references

The presentation sequence is consistent across the course: financial problem, intuition, theory, mathematics, algorithm, Python implementation, results, financial interpretation, model-risk discussion, and laboratory exercise.

## Reproducibility

The final course release will specify:

- Python 3.11 or later
- Google Colab and Jupyter
- NumPy, Pandas, Matplotlib, Scikit-learn
- imbalanced-learn, XGBoost, LightGBM, SHAP, and supporting libraries where required
- Fixed random seeds where stochastic results are used
- Clear separation between data instructions, code, outputs, and interpretation

Students remain responsible for understanding and explaining their own code, modelling decisions, and results.

## Responsible use of AI

AI tools may support debugging, documentation, concept clarification, and alternative implementations. They do not replace understanding, independent assessment work, source acknowledgement, or responsibility for submitted analysis.
