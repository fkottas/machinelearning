# Course Map

## Machine Learning in Finance · 13 weeks

The course follows the official NKUA syllabus and progresses from Python foundations to a complete financial machine-learning capstone.

| Week | Topic | Main application | Core output |
|---|---|---|---|
| 01 | Python Foundations I | Financial data introduction | Python foundations notebook |
| 02 | Python Foundations II: NumPy, Pandas, and EDA | Credit-risk data exploration | Exploratory data analysis |
| 03 | Data Cleaning and Preprocessing | Reliable modelling dataset | Reproducible preprocessing pipeline |
| 04 | Feature Engineering for Financial Data | Credit risk and fraud detection | Six to ten predictive variables |
| 05 | Logistic Regression for Credit Risk | Probability of default | Regularised logistic baseline |
| 06 | Model Evaluation and Performance Metrics | Credit-risk model assessment | Reusable evaluation toolkit |
| 07 | Decision Trees and Random Forests | Nonlinear credit-risk prediction | Ensemble benchmark |
| 08 | Model Validation and Generalisation | Robust financial ML | Generalisation diagnostics |
| 09 | Gradient Boosting Methods | Advanced credit scoring and fraud | Tuned boosting model |
| 10 | Alternative Machine Learning Algorithms | Comparative classification | Alternative classifier assessment |
| 11 | Calibration and Explainable AI | Explainable credit scoring | Calibrated PD model and SHAP analysis |
| 12 | Introduction to Neural Networks | Credit risk and fraud detection | Neural-network comparison |
| 13 | Capstone Project | Complete financial ML solution | Notebook, report, presentation, and supporting code |
